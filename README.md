# Dragons of Mugloar

Monorepo with three packages:

- `dragons-cli`: plays a full game from the terminal.
- `dragons-web`: React UI for playing the game in the browser.
- `dragons-api`: shared, typed client for the Dragons of Mugloar API

## Running

Instructions for running each app, with Bun or Docker, are in its README:

- CLI: [apps/dragons-cli/README.md](apps/dragons-cli/README.md)
- Web: [apps/dragons-web/README.md](apps/dragons-web/README.md)
